## 🚀 البدء السريع

### 1. استنساخ المشروع
```bash
git clone https://github.com/YohmorLive/1.git
cd 1
```

### 2. فتح الموقع
افتح `index.html` في المتصفح

### 3. الوصول للوحة التحكم
افتح `admin.html` في المتصفح

---

## 📁 هيكل الملفات

```
yohmor-live/
├── 📄 index.html      # الصفحة الرئيسية
├── 📄 admin.html      # لوحة التحكم
├── 🎨 style.css       # ملف التنسيق
├── ⚙️ app.js          # ملف JavaScript
├── 📊 data.json       # بيانات نموذجية للاستيراد
├── 📋 BRD.md          # وثيقة متطلبات العمل
└── 📖 README.md       # هذا الملف
```

## 💾 إدارة البيانات

### استيراد البيانات
1. افتح `admin.html`
2. اضغط على "استيراد البيانات"
3. اختر ملف `data.json`

### تصدير البيانات
1. افتح `admin.html`
2. اضغط على "تصدير البيانات"
3. سيتم تحميل ملف JSON

## 🌐 النشر على GitHub Pages

1. أنشئ repository جديد على GitHub
2. ارفع جميع الملفات
3. اذهب إلى **Settings** > **Pages**
4. اختر **Branch: main** و **/ (root)**
5. اضغط **Save**
6. انتظر دقائق ثم افتح الرابط
