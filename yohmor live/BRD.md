# Business Requirements Document (BRD)
# وثيقة متطلبات العمل

## مشروع: Yohmor Live - يحمر لايف
### المنصة الإلكترونية لبلدية يحمر الشقيف - لبنان

---

## 1. نظرة عامة على المشروع

### 1.1 وصف المشروع
منصة إلكترونية شاملة لبلدية يحمر الشقيف في جنوب لبنان، تهدف إلى تسهيل التواصل بين أبناء البلدة وتعزيز الأعمال المحلية من خلال دليل رقمي متكامل.

### 1.2 الأهداف الرئيسية
- نشر جميع الأعمال والخدمات المحلية (مؤسسات، جمعيات، مطاعم، خدمات)
- توفير نظام إشعارات للتحذيرات والأخبار
- تسهيل التواصل المباشر عبر WhatsApp
- تطوير البلدة وتحقيق أهداف السكان

---

## 2. المتطلبات الوظيفية

### 2.1 الموقع الرئيسي (index.html)
| الميزة | الوصف |
|--------|-------|
| عرض الأعمال | بطاقات تحتوي على اسم العمل، الوصف، الصورة، وزر WhatsApp |
| تصنيف الأعمال | فلترة حسب الفئة (مؤسسات، جمعيات، مطاعم، خدمات) |
| الإشعارات | عرض التنبيهات والتحذيرات والأخبار |
| التواصل | أزرار تواصل مباشر عبر WhatsApp |
| معلومات البلدة | قسم تعريفي عن يحمر الشقيف |

### 2.2 لوحة التحكم (admin.html)
| الميزة | الوصف |
|--------|-------|
| إدارة الأعمال | إضافة، تعديل، حذف |
| إدارة الإشعارات | إضافة، تعديل، حذف، تفعيل/إلغاء |
| استيراد البيانات | تحميل ملف JSON |
| تصدير البيانات | حفظ البيانات كملف JSON |
| إحصائيات | عرض أرقام الأعمال والإشعارات |

---

## 3. المتطلبات التقنية

### 3.1 التقنيات المستخدمة
- **HTML5** - هيكل الصفحات
- **CSS3** - التصميم والتنسيق
- **JavaScript (Vanilla)** - المنطق والتفاعلات
- **localStorage** - تخزين البيانات محلياً
- **Font Awesome** - الأيقونات
- **Google Fonts (Tajawal)** - الخط العربي

### 3.2 دعم المتصفحات
- Chrome (الأحدث)
- Firefox (الأحدث)
- Safari (الأحدث)
- Edge (الأحدث)

### 3.3 التوافق
- دعم كامل للغة العربية (RTL)
- تصميم متجاوب لجميع الأجهزة
- لا يتطلب خادم أو قاعدة بيانات
